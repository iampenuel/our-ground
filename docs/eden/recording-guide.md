# Our Ground product recording guide

Current scope: **the restored Our Ground website with genuine Gemini-powered Eden**. No standalone Meet Eden page or non-AI guide chatbot is accepted. The three-turn local acceptance is documented separately; this guide creates no video or deployment claim. Check the current verification record before recording newer clarification/voice behavior.

## Before recording

Use the original courtyard homepage and normal Support/Give/Organizations navigation. Follow the [current architecture](current-architecture.md) and [restored-product verification](verification/restored-product.md). Both legacy `/eden` and `/eden-assistant.html` entries redirect to `/support`; there is no separate Eden product/harness page.

Record the actual browser at a readable desktop or mobile size. Keep notifications, unrelated tabs, developer tools, account details, environment files, reviewer codes, and API keys outside the frame. Prefer a continuous take; disclose cuts or speed changes and never splice an invented result into a provider response.

Avoid source edits during a take. Build-output directories are now excluded from Vite's development watcher after logs confirmed that writing `dist/index.html` caused review-server reloads; source edits still trigger normal hot reload. Distinguish an actual document reload from the separately reproduced Support status-loading delay.

The current default is compact chat, approximately 390 × 480px on desktop, with a responsive mobile bottom sheet. Show optional Expand and Restore without losing the draft, messages, scroll position, context, or ongoing work. Both launcher and header reuse source-owned SVG animation of the exact approved PNG-derived layers, with the unchanged PNG during loading/error/reduced motion. Header controller/audio reactions preserve the baked smile; do not describe them as lip-sync. No normal or local AI-review portrait mounts Rive. Earlier native captures and the intermediate launcher-only SVG/header-Rive correction are superseded. The studio and unchanged RML/`.riv` references preserve their mandatory export branding without concealment or bypass.

Record welcome behavior separately: opening chat only hides the bubble for that page interaction; close and refresh without pressing X should welcome again. Only the actual X writes the v3 session dismissal, which survives route navigation and refresh in that session. A new session can welcome again, ambiguous v1/v2 flags are ignored, and blocked storage must not suppress the welcome. There is no timeout. For the reproduced local-review Support startup delay, show the existing site header/footer and accessible loading status while trusted status is pending, then the single full Support mount. Keep fresh browser evidence separate from earlier recordings.

If using the reproducible fictional API or eligible local evaluation data, keep its example labels legible. If using configured real resources, show their source/verification uncertainty and avoid implying that a listing guarantees availability. Do not record real resident circumstances or private account data.

## Unavailable inference and optional voice

If Gemini is unavailable, show the brief unavailable state or record the ordinary website controls separately. Do not continue a scripted conversation as Eden. A prior fictional-option comparison is dated engineering evidence, not a substitute for acceptance. Controlled testing now uses the original product in explicit local review mode and its actual HTTP API.

- Complete reviewer-code entry off-camera. Show the adult/data acknowledgement without exposing the code or key. Only proceed when the server admits the current supervised local session.
- Wait for each real response and underlying action result; do not substitute a saved answer, fake tool animation, or old comparison footage.
- If voice is actually available, explicitly unmute and play an approved Aoede phrase. Show speaking animation and Stop. Do not claim this is live microphone conversation or speech generated from unrestricted user input.
- If AI, quota, or speech fails, show the brief fallback honestly. Do not narrate the earlier successful test as though it occurred in the current take. Existing dated evidence may be linked separately.

Suggested caption after verified acceptance: “Our Ground — resource discovery with integrated Gemini-powered Eden. Recorded in an eligible local test using safe resource data; manual website controls work independently.”
