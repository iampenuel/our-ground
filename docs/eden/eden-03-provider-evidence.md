## Adult-focused release blockers and required evidence

1. **Actual audience/access evidence:** Determine whether this particular API client is likely to be used by minors, accounting for the public community-resource context. Record effective controls and legal/provider review; do not infer compliance from adult copy or a checkbox. A distinct restricted adult demonstration may be evaluated without changing the accessible public site's mission.
2. **User/operating geography:** Confirm the developer/operator is in a supported region and settle how an adult public client would exclude free-tier use where Paid Services are required. No geographic enforcement has been implemented. Do not collect precise visitor location merely to solve this without a separate privacy review.
3. **Free project attestation:** Operator must verify the project/plan, allowed models, quota and absence of active paid usage/billing changes. `EDEN_GEMINI_FREE_TIER_CONFIRMED=true` is an operator attestation, not an SDK determination. Default remains disabled.
4. **Actual data minimization:** Demonstrate that visitor content cannot become provider input, including fields, URLs, analytics, speech, exceptions and access logs. Current integration accepts finite action/context enums and fixed speech phrases only; genuine resident contexts remain local. Redaction is supplementary and imperfect. Any future personal-data processing requires a new provider/contract assessment.
5. **Purpose and contracts:** Document the professional/competition demonstration purpose, terms acceptance, privacy notices, controller/processor responsibilities, retention disclosures and applicable law. No DPA/BAA or HIPAA compliance for this free-tier prototype is verified. Resource navigation must remain outside medical advice/clinical practice.
6. **Hosted safeguards:** Public release additionally requires verified distributed abuse/session limits, key/project restrictions, host/platform logging controls, deletion operations and cost controls. The existing process-memory limits intentionally apply only to local synthetic development and cannot substantiate production readiness.

**Decision:** Conditional local synthetic adult development is a reasonable technical evaluation path once the operator confirms account/region/free-tier eligibility. Public Gemini remains **NO-GO** until the above evidence is reviewed. All-age public accessibility remains available through deterministic local navigation; evaluate a separate suitable provider/contract path for a future all-age AI service. No paid switch is authorized or assumed to cure eligibility.

## Backend review evidence

The backend independently denies public/hosted requests regardless of age acknowledgments or a public-enable environment flag, requires exact allowed loopback Origin and URL, and accepts only an expiring origin-bound opaque EDEN session. Supabase Bearer credentials are not accepted. It rejects raw message/city/resource/URL fields and real-data context before provider admission. It reconstructs finite provider inputs, disables Interactions state/automatic continuation/retries, and validates the single model function call against the originally approved action. Provider exceptions never return their original message. Fixed speech phrases share the same request/session/quota admission. These are implemented safeguards, not a legal eligibility finding.
