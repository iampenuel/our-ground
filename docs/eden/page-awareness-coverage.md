## Structured context and authority

The browser supplies an allowlisted public page enum, optional canonical city/category/radius, bounded result count and approved fictional record IDs, selected index, and finite search/map state. It does not scrape DOM text, forms, arbitrary record prose, URLs, coordinates or account data. [Public page facts](../../shared/eden-public-pages.ts) are application-owned descriptions inspected against the existing templates. The backend reconstructs resource facts from checked records; browser display titles are not grounding input.

`searchState` is `idle/loading/ready/error`. `mapState` is `not-shown/loading/ready/unavailable`, derived from the Support controller's actual map instance/loading/failure state. A selected result is not evidence that its map rendered or a service is open. Public pages outside Support/details contain **zero current result IDs** even when broad search slots are retained.

Both typed and Live actions use [applyEdenPublicAction](../../src/eden/live-actions.ts), the existing page adapter, and the same API-backed Support UI. New public navigation reuses reentrant original-template mounts and disposes old Support requests, map and listeners. The assistant node, in-memory conversation, call and canonical task slots remain outside the replaced page root. No new marketing page or alternate resource transport is introduced. Manual Back/Forward across document routes uses the existing safe document reload behavior.

## Data, privacy and release limits

Current AI grounding remains restricted to the two approved fictional API records. This is a live connection to the existing resource API/controller with demonstration data, not evidence that a configured real nationwide directory is currently connected. Historical imports, schema support or a successful fixture search do not prove current database connectivity, complete coverage or independently verified services. Real resource grounding needs its own approved source/privacy schema and eligibility review; none is activated here.

Successful canonical searches retain only city/category/radius and expiry for cross-page task continuity. Synthetic context stays in page memory; eligible nonsensitive public context may use the existing bounded tab setting. Results, titles, raw queries, precise coordinates and chat are not added to that setting. Reset clears it. Public page navigation preserves the current in-memory conversation rather than persisting it.

The local-review browser capability allowlist now covers the existing public assistant documents, allowing direct entry to Give/Organizations/About/Privacy in explicit loopback `eden-review` mode. Ordinary build/preview/public/private/API policies remain unchanged. Server transport/session/grant/free-project checks and hosted denial remain independent of this presentation permission. Typed requests still use finite reduction; raw Live microphone audio has the separate disclosure and privacy limitations documented in [Live local development](eden-live-local-development.md).
