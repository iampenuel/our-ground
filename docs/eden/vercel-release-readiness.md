## Current Vercel WebSocket support

**Vercel now supports WebSocket servers on all plans**, including Node/Bun implementations. Connections remain subject to function duration, reconnects may reach different instances, and durable state belongs in an external store. An old “Vercel cannot host WebSockets” assumption is not a valid architecture blocker. [Official WebSockets documentation](https://vercel.com/docs/functions/websockets), retrieved 2026-11-07.

EDEN currently uses **browser → Gemini WebSocket directly**, with HTTPS server requests for token minting and validated tools. No audio WebSocket proxy or platform migration is needed just because of historical platform limitations. Its blocking issue is hosted authorization/provider eligibility and distributed security state, not Vercel lacking WebSockets.

The current Functions limits list Hobby 300 seconds default/maximum; Pro/Enterprise 300 default, 800 maximum and 1800 extended maximum beta. This is a platform limit, not a budget or recommendation to increase call duration or change plans. Current token/tool HTTP work is bounded separately and does not keep a Vercel function open for the five-minute browser call. [Official Functions limits](https://vercel.com/docs/functions/limitations), retrieved 2026-11-07.

## Environment and operational separation

Use the existing owned infrastructure and a separately reviewed **Preview** environment. Public `VITE_` configuration is baked into browser assets; it may contain only intentionally public publishable values and the restricted browser map key. Database, migration, Redis and Gemini credentials must never use a browser prefix or be copied into reports. Keep owner/import connections separate from the restricted API role. Existing environment names are evidence of neither safe values nor least privilege.

Vercel's current controls distinguish readable **Config** values from write-only **Secret** values; Secrets are supported in Development as well. Build-log masking has documented conditions and does not replace safe application logging or output scanning. Use the correct type for each approved destination without reading back or printing secrets. No environment write was performed. [Official Config/Secret documentation](https://vercel.com/docs/environment-variables/sensitive-environment-variables), retrieved 2026-11-07.
