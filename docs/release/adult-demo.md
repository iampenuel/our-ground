## Provider and data handling

The independent production query returned zero published opening-hours rows for both HHC–South Allison Hill and Hamilton Health Center Family Practice at Steelton.

The authenticated Our Ground – EDEN Gemini Developer API project uses the Free tier. The hosted command and speech routes serve acknowledged adults in the United States. The app requests English on-device recognition only after the visitor taps Talk to EDEN. Google receives allowlisted directory commands, published listing facts and verified text for synthesis.
