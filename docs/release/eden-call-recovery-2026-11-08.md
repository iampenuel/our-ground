## Implemented fixes

- **Lease ownership:** finishing a session releases the matching visitor lease. Delayed, duplicated or wrong-session hangups cannot cancel a different call. Failed issuance releases provisional capacity. The two independent provider-risk slots remain bounded until credential expiry: a browser cannot prove an already delivered credential was revoked. A saturated capacity slot now returns a distinct 429 with bounded Retry-After. Attempt and mint budgets are unchanged. The protected staging database gained one narrow compare-and-delete function; browser/service roles have no function access or raw table permissions.
- **Browser failures:** a call now preserves its correlation ID, stage, HTTP result, fixed provider/close categories, numeric close code, setup status, input/output counts and cleanup outcome. Chrome's error event no longer discards the following close event. The last three sanitized receipts live only in page memory; Call details is available on failure. No raw error text, audio, transcripts, tokens or permanent keys are collected. Each explicit retry can start in the same panel; hangup completion is sequenced before the next mint.
- **Spoken interruption:** older PCM and a separate old turn-complete can arrive after local playback has stopped. The regression demonstrates that processing those packets as a new answer prematurely stopped microphone forwarding. Eden discards the superseded reply until its boundary and preserves the visitor's new utterance. Brief packet gaps no longer close barge-in capture. “Show me the first result” now explicitly calls for the authorized detail action. This is a reproduced defect; the historical first disconnect cannot be retrospectively attributed to it.
- **Wordmark:** the generic width-limited container won the CSS cascade in the header while the hero used a viewport gutter. On the failed desktop candidate their left edges were 126 and 60 CSS pixels. The homepage header, headline and community content now use the same responsive edge; the wordmark is still a native homepage link with visible keyboard focus.
- **Cursor and character:** speed changed from 1.8 to 0.7, from a fixed 240 ms request to distance-aware travel; configured hover is 300 ms and press ~129 ms after scaling. Removed a repeated 643 ms entrance pause. In two real browser traces the target-to-execute interval fell from 1.88–2.19 s with that extra pause to 1.20–1.48 s without it; all ten targets landed. Cursor events describe actual authorized targets; visual clicks cannot execute page actions. The approved public expressive portrait is the SVG layer renderer. Rive assets and local native states were verified separately; the cropped public Rive export lacks the expressive inputs. [Character evidence](eden-live-action-recovery-2026-11-08.md).
