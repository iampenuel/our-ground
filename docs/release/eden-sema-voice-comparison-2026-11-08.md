# SEMA and Eden voice architecture · November 8, 2026

This report records the earlier recovery checkpoint. For the subsequent hosted call implementation, exact deployed SHA and physical acceptance status, see the [Eden call recovery report](eden-call-recovery-2026-11-08.md).

**Finding.** SEMA is a useful reference for turn-taking and tool authorization. Its Live transport streams microphone audio to Google. Hosted Eden currently keeps dictation on the device and sends bounded public concepts to its text model; “Read reply” separately requests speech for an already verified answer. Making Eden conversational over a live microphone would change both the privacy boundary and how the service consumes quota.

### The two SEMA connection paths

The SDK adapter uses `@google/genai` 2.9.0, a short-lived token, and `v1alpha` `live.connect`. Its session builder requests audio output, both transcriptions, sliding-window compression, low-sensitivity automatic voice detection, activity-only turns, and no interruption. The adapter keeps connection and response epochs, drops duplicate parts, and distinguishes generation completion from turn completion. [Model and environment defaults](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/lib/live/liveConfigCore.ts) · [SDK session configuration](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/lib/live/liveSessionConfig.ts) · [SDK provider](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/lib/live/providers/geminiLiveProvider.ts)

The inspected UI hook actually constructs a **different client**, `GeminiLiveIntroClient`. It starts the output player, requests microphone permission, obtains a token, opens a constrained WebSocket, waits for setup acknowledgement, and sends the introduction once. Its raw setup includes audio, voice, thinking, output transcription, system instructions and tool declarations. It does not explicitly send the SDK builder’s sliding window, input transcription or VAD settings. Its GoAway and resumption handlers count notifications; those handlers do not reconnect or resume the call. A product deadline and cleanup terminate the session. [Session hook](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/hooks/useSemaLiveSession.ts) · [Raw setup](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/lib/live/liveIntroControl.ts#L363) · [WebSocket client](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/lib/live/liveIntroClient.ts)

SEMA’s POST route checks the Origin host and configuration, rejects a repeated nonce, rate-limits to three mints per minute per network bucket in process memory, and returns a no-store token response with model/voice settings. Its mint sets one use, a 60-second connection window and bounded expiry. It does not bind the model/tools configuration into the minted token. The route has no Eden-style signed adult/region/session gate. Production additionally requires SEMA’s public-demo flag. [Token policy](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/lib/live/liveTokenPolicy.ts) · [POST route](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/app/api/ai/live/token/route.ts) · [Mint implementation](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/lib/live/ephemeralToken.ts)

### What carries over

- **Turn-taking.** Combine the provider’s turn-complete event with actual output drain before reopening the microphone. Bound waits, discard late events from earlier connection generations and let the user stop. Eden’s local session already does this and permits one bounded recovery with a valid resume handle at a safe turn boundary. Reuse that controller before introducing a second one. [Eden session](../../src/eden/live/session.ts) · [Transport](../../src/eden/live/transport.ts)
- **Context and tools.** SEMA defines a versioned application snapshot and checks tool arguments, eligibility, permission and duplicate calls. Its clinical folder metadata is specific to SEMA. Keep Eden’s public-route, city, filter, visible-ID and verification projections; omit account fields, arbitrary DOM, raw user wording and private records. Eden’s local Live tool vocabulary is limited to `read_public_page_context`, `perform_public_resource_action` and `ask_clarification`. Live proposals must use the same application executor, confirmed outcomes and cursor as text. A spoken request is not authorization to edit an organization or spend money. [SEMA context](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/lib/live/buildLiveSessionContext.ts) · [SEMA tool checks](https://github.com/iampenuel/sema/blob/7175581dee3193303316e3dc51a767606734eebf/lib/live/liveTools.ts) · [Eden tool authorization and reconciliation](../../src/eden/live-actions.ts)
- **Credentials.** Keep the server key server-side. Eden pins SDK 3.0.0. Its local experiment mints one-use tokens constrained to the exact v1beta model/setup, binds calls to the session, expires unused connections after at most 60 seconds and blocks overlapping or replayed grants. The local process counters and leases are insufficient for a public serverless fleet. [Eden Live mint](../../backend/eden-live.ts) · [Approved setup](../../shared/eden-live.ts) · [Local admission](../../backend/eden-api.ts)

**Before the later protected pilot, hosted Talk to Eden was disabled.** At that stage the hosted status reported `rawAudioAccepted:false` and `liveTokensAvailable:false`. `EDEN_HOSTED_COMMANDS=enabled` operates the bounded text/TTS service; `EDEN_GEMINI_MODE=disabled` keeps the separate synthetic-development path closed. Reusing the SEMA model name, raising a limit or flipping its equivalent flag would not establish service eligibility.
