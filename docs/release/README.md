# National release candidate

The application exposes three searchable categories. The source counts come from the restricted staging database’s public projection. See [coverage and query receipts](coverage.json) for each jurisdiction, category and source. Washington, DC and supported territories have separate rows. External referrals never contribute to these totals.

## Geography and sources

| Source | Staging listings | Scope and admission rule |
|---|---:|---|
| HRSA Health Center Service Delivery and Look-Alike Sites | 16,417 | Active fixed/seasonal service delivery or mixed administrative/service sites, public address, valid point, supported jurisdiction. Includes every state. School and other institution-based programs may restrict access. |
| Philadelphia Free Food and Meal Sites | 324 | City-licensed feed. Excludes benefits-only, inactive and coordinate-conflict records. |

| HUD Housing Counselor API | 508 | Active agencies with explicit face-to-face counseling, a usable public address and plausible coordinates near a Census place in the stated jurisdiction. No mailing addresses or email fields imported. The source supplies the retrieval date only. |

The November 5 HRSA snapshot had 19,537 raw rows and produced the historical 17,418 fixed-site records. The November 6 snapshot has 19,569 rows. The old importer admitted administrative offices. The revised allowlist excludes administrative-only and unknown service types and keeps mixed sites that deliver care. Stable IDs continue to use the source site number. The November 7 download matched the preserved November 6 feed byte for byte. The 367 protected pilot records were a deliberate slice. The 593 historical food programs came from three municipal feeds, including 269 outside the Pennsylvania pilot. See [historical HRSA evidence](../implementation/phase-7d-hrsa-coverage.json), [regional food review](../implementation/final-discovery-food-expansion.md) and [source import receipts](imports.json).

The current HUD API returned 1,368 unique agencies. The static GIS catalog describes 2022 geographic coverage. The candidate instead uses the public counselor query service. Agency coordinates can be approximate, and the listing gives no assurance of walk-in availability, eligibility or fees. The search page also offers HUD and 211 referrals when it has no local match. OpenStreetMap’s ODbL requires attribution and may require distributing a derived database under the same license. This release keeps transient mapped leads separate from directory records. SNAP retailers sell eligible food for benefits. Summer meal sites have specific dates and youth eligibility. Neither source was added to the free-food inventory. ## Reviewed refresh

Use Node 24 and the pinned lockfile. Keep raw data and owner credentials outside Git. Save the bounded official HRSA CSV as `latest.csv`, the two reviewed municipal exports as `seattle-food-resources.json` and `pgc-food-assistance.json`, and the unmodified HUD counselor response as `hud-response` with its ISO retrieval time in `hud-captured.txt`. The Philadelphia feed has a separate existing review workflow. All source data is independently attributed and labeled imported/unverified.

Run `node --experimental-strip-types scripts/national-import.mjs <private-folder> plan`. Review source dates, individual exclusions, withdrawals, duplicate identities, changes to bindings and proposed counts against the previous receipt. Retain the raw hashes privately. The plan prints a fingerprint. Run the same command with `rehearse <fingerprint>` on the isolated restore first, and with `protected-staging <fingerprint>` only after review. The operator script pins the existing staging project and rejects a production runtime. Each source uses its own transaction, advisory lock and receipt so that completed sources can be retried. The source identifier, raw hash, policy and retrieval date determine what was reviewed. A fingerprint verifies the selected input and does not appoint a reviewer. No scheduled import or automatic approval runs.

A new HUD snapshot can withdraw a missing or newly ineligible published agency. Withdrawn IDs remain held out of later imports pending human reconciliation. HRSA confidential IDs and conflicting food coordinates retain their existing holds. HRSA missing rows enter stale review. Corrections remain private and require human disposition. A listing for which confidentiality is in question should be withdrawn from search, detail and map together. Reinstatement requires fresh publisher evidence and an authorized reviewer.
