# Security policy

Please report suspected vulnerabilities privately to
[ourground-support@googlegroups.com](mailto:ourground-support@googlegroups.com).
Include the affected component, impact, and safe reproduction steps. Do not open
a public issue or pull request containing a vulnerability, credentials, session
tokens, personal data, or private test evidence.

Do not send passwords, API keys, access tokens, or raw user conversations. Describe
where sensitive material was found without copying it into the report. Use only
accounts and data you are authorized to test; do not disrupt the production site.

Security fixes target the current production release. Reviewers will assess the
report and coordinate any required remediation and disclosure.
